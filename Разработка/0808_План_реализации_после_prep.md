## 0. Принципы

1. **Сначала репо, потом ноутбук.** Физика и тюнинг живут в `src` / скриптах / рабочем ноутбуке 7; Colab-self-contained собираем после прироста метрик.

3. **Prep не трогать без причины.** Константы окон PSD `(5, 50)` и feature contract — baseline; менять только если gate/устойчивость требуют.
4. **Legacy §5–§9** — референс, не эталон. Новый блок моделей — поверх live `X_clust`.
5. Порядок: prep (готово) → HP → класс 2 emergent → LB → SHIP.
6. **Модели:** те же семейства (GMM / KMeans / порог PSD), не экзотика; финальный рецепт (квота 5%) — не эталон.

## 4. FE-2 — HP на живых признаках (M, critical path)

**Кандидаты моделей (минимум)**
1. Порог / GMM-1D по калиброванному **PSD** (две моды + долина).
2. **GMM-2** на `X_clust` (перебор `covariance_type`, init, `n_init`; `RANDOM_STATE`).
3. Опционально: GMM-3 / KMeans-3 — только как диагностика, не как «натянуть 3 класса».

**Proxy оптимизации (разрешены)**
- устойчивость `valley_ratio` / разделение мод PSD;
- holdout / bootstrap стабильность долей;
- LB / валидационный score конкурса;
- log-likelihood / BIC для GMM (вторично).

**Proxy запрещены как цель**
- «доля класса 2 ≈ 5%»;
- максимум silhouette в одиночку.

**DoD:** выбран baseline-классификатор 0/1 (или 2 компоненты) + таблица HP; без квоты в определении победителя.

## 5. FE-3 — Политика класса 2 (M)

**Сделать**
- Класс 2 = **emergent**:
  - события в **overlap** долины PSD (окно вокруг split / низкой плотности между модами);
  - и/или физические `qc_*` (pile-up, no_3σ, decay→конец, saturated, nonfinite);
  - при необходимости — абсолютный порог неуверенности GMM (`1 - max(proba) > τ`), **не** `top q%`.
- Запрет: `uncertain_fraction` как единственный рычаг финала.
- Отчёт: «получилось X% класса 2», без формулировки «по ТЗ 5%».

**DoD:** доля класса 2 — результат политики; политика описана в markdown; сравнение с квотой 5% только как ablation.
