| Поле | Значение |
|---|---|
| **Ветка** | `light` |
| **Роль** | Архитектор + физика волны (гипотеза света) |

---

## 0. Канон (высечено на кристалле)

> **Тип** = характер угасания после выравнивания фронта.  
> **Отказ (класс 2)** = только когда угасание неизмеримо.  
> **Энергия** правит ширину отказа, не имя волны.

Контракт трёх часов:

| Час | Смысл | Что меняет |
|---|---|---|
| **Формы** | \(\rho\) или честный \(\tau_{\mathrm{eff}}\) / PSD после фронт-align | метка 0/1 |
| **Энергии** | \(f(E,\mathrm{SNR})\) только ширина отказа | сколько точек → 2 |
| **Честности** | плохой fit / нестабильная \(\tau\) → 2 | запрет насиловать 0/1 |

---

## 1. Цель сценария

1. Переписать **предобработку** под физику двух компонент высвечивания + выравнивание фронта.  
2. Зафиксировать **пространство признаков** для типа (не амплитуда как главный голос).  
3. Выбрать **модель границы** 0/1 и политику класса 2 по честности, не по «слабый = мусор».  
4. Явно искать **границу смешения в области угасания** (перешеек по \(\rho\)/\(\tau\)), не по чужим признакам.

DoD эпика LIGHT: submission с LB **> 0.85838** *или* явный stop с диагностикой «почему \(\tau\) не отделил».

## 2. Предобработка (новый контракт)

Код-цель (ориентир): расширить / рядом с `src/sygnal_clustering/signal_extraction.py` модулем  
`src/sygnal_clustering/light_decay.py` (не ломать FE-champion prep без апрува).

### 2.1. Общее (наследовать из prep)

- Полярность `negative`, baseline первые `BASELINE_BINS`, `x0 = x_pos - baseline`.  
- Шум \(\sigma\) из baseline-окна.  
- QC-флаги: nonfinite, saturated, no_3σ — как диагностика; **не** автоматом весь QC → class2 (уже вредило).

### 2.2. Выравнивание фронта (обязательно, час формы)

Для каждого импульса на `x0`:

1. `peak = max(x0)`, `i_peak = argmax` — только для оценки амплитуды.  
2. **t0 (рождение для сравнения форм):** первый отсчёт на фронте, где  
   \(x0[t] \ge \alpha \cdot peak\), \(\alpha \in \{0.1, 0.2, 0.3\}\) (старт **0.2**).  
3. Все последующие окна PSD / fit отсчитывать от **t0** (или от `t0 + offset`), не смешивать фазы argmax.

Стоп-критерий: если фронт не найден / пик < kσ → флаг `qc_no_front` (кандидат часа честности).

### 2.3. ROI long-gate

- База: 3σ-конец как сейчас (чемпионская физика ROI).  
- A/B позже: ROI от t0 до 3σ; не смешивать с тюнингом \(\alpha\) в одном upload.

### 2.4. Двухкомпонентное угасание (ядро LIGHT)

На хвосте после отступа **40% амплитуды** от пика (как Description), на `x0` или `x_norm`:

\[
I(t) = A_f e^{-t/\tau_f} + A_s e^{-t/\tau_s}
\]

Оценка (практичный порядок):

1. **LIGHT-A (обязательный MVP):** одноэкспоненциальный \(\tau_{\mathrm{eff}}\) после 40% — честный fit (least squares / polyfit на `log`), не «время до порога = 3 у всех».  
2. **LIGHT-B:** двухэкспоненциальный fit с ограничениями \(\tau_f < \tau_s\), \(A_f,A_s>0\);  
   \[
   \rho = \frac{A_s \tau_s}{A_f \tau_f + A_s \tau_s + \varepsilon}
   \]
3. Метрики честности fit: \(R^2\), относительная ошибка, условие числа точек хвоста ≥ N_min → иначе `qc_bad_decay_fit`.

### 2.5. PSD как упрощение часа формы (контроль)

Сохранить чемпионский PSD `(L−S)/L` окна (4,42) **после фронт-align** как контроль:

- `PSD_argmax` — текущий чемпион (референс).  
- `PSD_front` — short/long от t0+offset.  

Первый честный A/B LIGHT: только замена точки отсчёта окон (фронт vs argmax), без смены формулы.

### 2.6. Выходы prep LIGHT

Таблица признаков на событие:

| Поле | Час |
|---|---|
| `t0`, `alpha`, `i_peak`, `peak_above` | формы / QC |
| `tau_eff`, `rho` (если B), `fit_r2`, `qc_bad_decay_fit` | формы / честности |
| `psd_front`, `psd_argmax` | формы (контроль) |
| `charge_roi`, `snr` | энергии (только отказ) |
| `valley_*` глобальные по выбранной оси формы | границы |

## 3. Выбор моделей / решателей

Принцип: **сначала 1D форма**, многомерное — только если 1D-LIGHT бьёт чемпиона или честно объясняется проигрыш.

### 3.1. Модель M0 — контроль (заморожен)

Чемпион: `psd_argmax`, thr = valley+0.003, class2 = PSD∉[q1.5%, q98.5%].  
Score-референс: **0.85838**.

### 3.2. Модель M1 — LIGHT tau/rho threshold (основная)

1. Ось формы: `tau_eff` (MVP) или `rho` (B) или `psd_front`.  
2. Найти долину (`valley_ratio` gate как в prep).  
3. `lab = 1` если значение > valley+δ (полярность по смыслу: больший хвост / больший \(\tau\) → один тип).  
4. Class2 **только** из часа честности ∪ узкого хвоста оси формы (не SNR-оптом в soft).

Запрещено как цель: квота 5%; soft-zone на decay_time старого prep.

### 3.3. Модель M2 — поверхность отказа

Для событий с хорошим fit:

- 0/1 по M1 с **глобальным** (или слабоэнергетическим) порогом формы.  
- Ширина class2:  
  \[
  \text{reject if } \mathrm{SNR} < s_{\min}(E) \ \textbf{или}\ \texttt{qc_bad_decay_fit}
  \]
  где \(s_{\min}\) почти 0 для ярких и растёт только внизу по энергии — **калибровка ширины**, не смена порога типа.

Стартовать после того, как M1 на хорошем fit не хуже M0.

### 3.4. Модель M3 — граница смешения в угасании (исследование)

Не голосование PCA/decay. Объект исследования — **перешеек по оси формы LIGHT**:

1. Построить гистограмму `tau_eff` / `rho` / `psd_front`.  
2. Выделить band `|x - valley| < h`.  
3. Внутри band описать: SNR, peak, fit_r2, длина хвоста — карта как `isthmus_map`, но на новой оси.  
4. Решение в band:  
   - либо оставить M1;  
   - либо class2 только при `fit_r2 < r_min`;  
   - **не** flip по SNR (опровергнуто isthmus на PSD).

Успех M3: рост LB или доказательство, что смешение на LIGHT-оси уже́е, чем на PSD.

### 3.5. Что не выбирать на старте LIGHT

- GMM-2/3 на смеси амплитуда+форма как финал.  
- Description-compose (уже −0.02…0.03).  
- Сетка новых алгебр `(L−S)/(L+S)` без фронт-align.  
- Энерго-квартили с отдельной valley (H-radio отвергнута).

## 4. Поиск границы смешения (протокол)

```text
LIGHT-0  freeze M0 submission (байт-в-байт чемпион)
LIGHT-1  front-align + psd_front  (одна ось, тот же class2)     → upload #1
LIGHT-2  tau_eff after 40% + valley split + honesty→2           → upload #2
LIGHT-3  rho two-exp (если tau_eff не хуже/лучше)               → upload #3
LIGHT-4  isthmus map на лучшей оси; honesty-only в band         → upload #4
LIGHT-5  M2 поверхность отказа f(E,SNR) узко                     → upload #5
```

Правила upload:

- Редкие: не более 1 гипотезы на заливку.  
- Стоп оси, если два подряд ≤ 0.85838 без диагностического выигрыша (лучший valley_ratio / уже́е перешеек).  
- Любой рост > champ → зафиксировать freeze.json + не откатывать prep LIGHT.

## 6. Риски

| Риск | Митигация |
|---|---|
| Fit \(\tau\) даёт константу (как старый decay=3) | жёсткий QC fit; иначе не использовать ось |
| Фронт-align ломает чемпионский PSD | держать M0; A/B только `psd_front` |
| Class2 снова «слабые оптом» | запрет; только bad fit / форма-хвост |
| Двухэкспонента нестабильна | сначала tau_eff MVP |

---

## 7. Критерий «сценарий выполнен»

1. Есть воспроизводимый LIGHT-prep (фронт + \(\tau_{\mathrm{eff}}\) + QC fit).  
2. Есть M1 submission и запись LB.  
3. Есть карта смешения на оси угасания (не на старом decay).  
4. Либо LB > 0.85838, либо документированный stop с причиной.

---

## Одной фразой

Сначала выровнять рождение вспышки по фронту, измерить честное угасание, резать тип по форме, а в отказ отдавать лишь то, что волна не даёт измерить — энергия лишь регулирует ширину этой честности.
