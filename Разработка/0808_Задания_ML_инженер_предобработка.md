## TASK-PREP-S2 — Discrimination: PSD gate + нормировка

| | |
|---|---|
| **US** | US-3, US-4 |
| **Оценка** | L (critical path) |
| **Приоритет** | P0 |
| **DoD** | D3, D4', D5, D11 на psd/decay/x_norm |

### Зачем
Единственный измеримый gate эпика: бимодальность PSD **или** decay. Без него модели сравнивать рано.

### Сделать

**A. PSD (US-3)**  
- Default: `psd = (long − short) / (long + EPS)`.
- `short/long` — только A/B-диагностика, не в default `X_clust`.
- Сетка `(PSD_OFFSET, PSD_SHORT)`: **`len(grid) ≤ MAX_GRID_POINTS` (≤64)**; калибровка `valley_ratio` на subsample **`≤ CALIB_SUBSAMPLE`** + `RANDOM_STATE`; финальный прогон на полной выборке с победившими константами.
- Метрика:
  ```text
  valley_ratio = density(valley) / (mean(density(mode1), density(mode2)) + EPS)
  gate OK ⇔ valley_ratio < VALLEY_RATIO_MAX   # default 0.7
  ```
- Edge-cases: мод < 2 → FAIL; мод > 2 → две доминирующие / документировать.
- Параллельно тот же `valley_ratio` на decay (канал «или» в DoD).
- Гистограммы до/после с отмеченной впадиной; значение `valley_ratio` в выводе.
- Если gate FAIL — markdown **STOP** к новым моделям; FE для диагностики всё равно посчитать.

**B. Нормировка (US-4)**  
- `x_norm = x0 / (peak_above_baseline + EPS)`.
- `decay_time` на `x0`/`x_norm`:  
  `thr = (1 - DECAY_FRAC) * peak_above_baseline`  
  (спад на 40% → уровень **60%** амплитуды; **не** путать с порогом `0.4 * peak_above`).
- `is_saturated` как QC.
- Сырые `peak` / старый `snr` **не** в default матрице кластеризации.
- D11: `isfinite` на `x_norm`, `psd`, `decay_time` до расчёта gate.

### Acceptance
- [ ] Формула PSD зафиксирована константой Description
- [ ] `MAX_GRID_POINTS` / `CALIB_SUBSAMPLE` соблюдены
- [ ] Есть `valley_ratio` + картинка
- [ ] Gate PASS или явный блокер в markdown
- [ ] Decay на верной оси с правильным порогом
- [ ] Три контракта окон не склеены
- [ ] D11: `isfinite` на `psd` / `decay` / `x_norm`

### Критерий приёмки
Тимлид + (желательно) физик смотрят гистограмму: видна долина **или** принят документированный блокер. Silhouette **не** аргумент закрытия S2.

## TASK-PREP-S3 — QC, feature contract, scaler, интеграция

| | |
|---|---|

### Зачем
Зафиксировать контракт признаков для EPIC-FE и честно отделить legacy-модели с квотой 5%.

### Сделать

**A. QC (US-5)** — только флаги, не метки  
Минимум: multi-peak/pile-up; decay упирается в конец окна; ROI outliers; baseline drift; PSD вне коридора; **`qc_nonfinite`**.  
`candidate_class2` = OR/AND физических `qc_*`; доля **emergent**.  
**Запрет:** финальный `cluster`; «5% по ТЗ»; **`top q%` uncertainty/posterior/score как способ собрать candidate**.  
Сводка долей флагов. Модель 5 не трогать.

**B. Feature contract (US-6)**  
Default: `psd_calibrated`, `decay_time`, `charge_roi`, `tail_ratio`.  
Near-zero variance — отчёт / понижение веса.  
`feat_df.describe()` + markdown «что кормим моделям».  
τ-fit — опциональный флаг, не блокер.  
D11 финал: `isfinite` на всей default feature-матрице до scaler → иначе `ValueError`.

**C. Scaler (US-7)**  
`RobustScaler` и/или `QuantileTransformer` с `RANDOM_STATE` только на непрерывных живых признаках.  
QC-бинарные **не** скейлить.  
Контрольный PCA/EVR: если PC1≈100% — риск в выводе (не блокер при живой PSD).

**D. Интеграция (US-8) + D12**  
- Баннер перед §5: legacy / pre-prep / квота 5% условна / актуализация — EPIC-FE.  
- Чеклист D0–D12 в конце § Preprocessing.  
- Нет `pip` ни в prep, ни в deps-ячейке этого PR; нет joblib/pickle; NPY только с `allow_pickle=False`.  
- **Рекомендуется:** SHA256 входного `Run200_Wave_0_1.txt` в markdown prep.  
- Краткая запись статуса Done/blockers в `Разработка/Ревью/` (согласовать с тимлидом).
