Квота **5%** для класса 2 — не просто «спорный инженерный трюк». По числам из outputs ноутбука она **не соответствует физической неоднозначности**: GMM почти везде уверен, а текущий PSD вырожден («стена» ~0.06). ## 2. Про «класс 2 нарисован 5%»

Замечание ревьюера **усиливается физикой**, не ослабляется:

1. В Description (§2.3.2) неоднозначность — это **перекрытие двух распределений около split point**, а не «нижние 5% по posterior».
2. У текущей модели posterior почти везде ≈1 → квота 5% **не измеряет** область overlap.
3. Формулировка «~5% по ТЗ» ложна: ТЗ просит класс аномалий/неоднозначных, **без доли**.

Инженерный трюк здесь не в самой идее «2 типа + хвост», а в том, что хвост **квотирован**, хотя observable (PSD) ещё не восстановлен.

## 3. Скорректированный вектор исследований

### Не туда (текущий вектор)

Максимизировать silhouette / подобрать долю класса 2 / сравнить 5 кластеризаторов на почти мёртвых `[peak, charge, psd]`.

### Туда (физика → затем ML)

**1. Сначала восстановить наблюдаемую PSD (главный приоритет)**  
Как в Description: варьировать **offset** и **длину short gate**, пока гистограмма PSD не покажет **два пика и долину**.  
Пока ~91% сидят на стене 0.06 — любая кластеризация на этом PSD физически слепа.  
Параллельно проверить формулу: в Description часто `(long−short)/long`, в ноутбуке `short/long` — согласовать и калибровать окна.

**2. Классы 0/1 = γ/n по форме, не по charge-1D**  
Рабочее пространство: **настроенный PSD + decay/время высвечивания** (± нормированная форма хвоста).  
Peak/SNR — только диагностика насыщения и качества волны, не входы финальной кластеризации.  
GMM-2 / порог по долине гистограммы — после появления бимодальности.

**3. Класс 2 = emergent residual, не квота**  
Физически мотивированные кандидаты (доля пусть получится сама):

- события **в overlap** двух PSD-мод (то, о чём прямо пишет Description);
- морфология: pile-up / двойной пик / неспадающий импульс (`decay→500`) / обрыв baseline;
- при необходимости — Isolation Forest / низкий likelihood **по абсолютному порогу**, не `top 5%`.

Сообщать: «получилось X% класса 2», а не «задали 5%».

**4. ML-сравнение — после физики**  
Когда PSD оживёт: GMM-2+residual vs порог по PSD vs композиция (PSD + decay + PC1 в плоскости амплитуда–заряд из Description).  
Метрики: форма гистограмм, устойчивость долины, Kaggle; silhouette — вторичен.

**5. Remap 0↔1**  
Только после устойчивого разделения формы; критерий — физический (медленный vs быстрый хвост / PSD), не «средний charge», пока peak насыщен.

## 4. Практический порядок работ

1. Сетка `(psd_offset, psd_short)` → критерий качества: глубина долины / разделение мод.  
2. Зафиксировать PSD; построить γ/n (0/1).  
3. Определить класс 2 правилами residual из п.3; **доля — результат**.  
4. Только потом тюнить пороги и сравнивать модели под LB.  
5. В тексте решения явно: «5% был эмпирический prior; заменён на физический residual».

## 5. Одной фразой

Сейчас кластеризуются **насыщенный АЦП и вырожденный PSD**, а класс 2 рисуется процентом там, где неопределённости почти нет; правильный вектор — **вернуть бимодальную PSD/форму высвечивания**, разделить γ/n по хвосту, а аномалии искать в overlap и патологиях импульса, пусть их доля будет какой получится.
