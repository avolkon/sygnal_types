## 1. ML-архитектор

**Вердикт:** prep достиг цели эпика — **representation починен**. Можно открывать осмысленный HP. Это ещё **не** победа в конкурсе.

### Что доказано числами

- Старый SNR ≈1 и PSD-стена — артефакты пайплайна; после baseline/полярности SNR ~692 → сигнал реально отделён от пьедестала.
- Смена формулы PSD + калибровка окон `(5, 50)` дали `valley_ratio ≈ 0.06` при пороге 0.7 → **gate PASS**. Появился измеримый критерий готовности признаков, которого раньше не было.
- PC1 ~61% вместо ~100% → пространство **перестало быть одномерным charge**. Есть на чём сравнивать модели без вырождения в «одну ось».
- `candidate_class2` ~2.9% emergent → убран circular prior «доля = 5%» на уровне prep. Контракт признаков отделён от legacy §5–§9.

### Что это значит для следующего шага

Цепочка из `0808_Связь_prep_HP_класс2.md` разблокирована: живые признаки → можно тюнить GMM/пороги/состав фич с proxy ≠ «доля 5%».  
Legacy-модели под баннером **нельзя** читать как оценку качества prep: они всё ещё могут тащить старую логику меток.

### Риски / дыры

- Smoke — один прогон; нет жёсткой фиксации SHA256 / долей `no_3σ_hit`, устойчивости окон на другом subsample.
- PC1 61% — хорошо, но не гарантия трёх физических классов; нужна валидация кластеризации на `X_clust`.
- Конкурсный score после prep **ещё не измерен** → нельзя утверждать «результат повышен».

### Итог архитектора

Эпик prep **закрывает блокер**; файнтюн теперь легитимен. Успех = метрики на новых признаках + честный класс 2, не чеклист D0–D12 сам по себе.

## 2. Учёный-физик

**Вердикт:** восстановлена **рабочая наблюдаемая форма импульса** для pulse-shape discrimination. Это необходимое условие γ/n-разделения. Сами типы частиц prep **ещё не доказал**.

### Физический смысл метрик

- **Отрицательная полярность** согласуется с картиной «спад на высоком пьедестале АЦП»: без отражения `argmax` ловил пьедестал, а не импульс.
- **Baseline → x0 → 3σ ROI:** charge считается по области сигнала до возврата к шуму, а не по всей длине записи — правильная интегральная мера заряда в окне высвечивания.
- **PSD `(long−short)/long` + окна (5, 50):** появление долины (`valley_ratio ~0.06`) — сильный признак, что параметр чувствителен к **разной форме хвоста**, а не к константе ped/ADC. Это соответствует Description.
- **SNR ~692:** амплитуда ≫ шума пьедестала — импульсы «живые»; старый SNR≈1 был диагностикой сломанной оси, не физики детектора.
- **PC1 ~61%:** кроме заряда есть вклад формы (PSD/decay/tail) — пространство ближе к плоскости «заряд–форма», а не к одной амплитуде.

### Чего физика ещё не сказала

- Бимодальность PSD ≠ автоматически **γ vs n**. Нужна интерпретация мод (быстрый/медленный компонент) и устойчивость split при вариации окон / subsample.
- Калибровка `(5, 50)` — эмпирический оптимум `valley_ratio`, не измерение времён высвечивания в нс; физическую привязку окон ещё стоит сверить с Description / типичными gate.
- Класс 2 ~2.9% из QC — **кандидаты артефактов/аномалий**, не доказанный overlap γ/n у долины. Overlap по PSD отдельно от QC ещё нужно строить.
- Насыщение пика (раньше peak был почти константа) никуда не делось как свойство АЦП: peak по-прежнему плохой дискриминант типа; правильно, что его нет в default `X_clust`.

### Итог физика

Prep вернул пайплайн в область, где **можно** искать типы частиц по форме. Сейчас есть живой PSD-gate; **нет** ещё закрытой физической разметки 0/1/2 и нет доказательства, что моды = γ/n.
