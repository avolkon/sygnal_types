## Ответ консилиума

### 1. Доктор физико-математических наук (математика)

Пространство поиска вокруг чемпиона уже локально «выпукло вниз»: соседи по окнам / δ / outlier / σ стабильно хуже или равны.  
Прирост 0.0001–0.002 — флуктуации границы; **+0.08** из микросдвигов thr **математически не следует**.

**Гипотеза потери баллов:** либо шум / другая скрытая ось разметки, либо метрика считает не то, что оптимизируем (не чистый accuracy по фиксированным 0/1/2 без remap).

**К 0.94–0.96:** нужна **другая решающая статистика**, не ещё один grid по `(offset, short, q)`.

---

### 2. Нобелевский лауреат по ядерной физике

PSD оживили — это правильный вектор для γ/n. Но **0.86 ≠ конец физики**: pile-up, послеимпульсы, насыщение АЦП, разный light yield.

**Где теряются баллы:** события с «чужой» формой в PSD (не две чистые моды), которые мы всё равно режем одной долиной; class2 по квантилям — не физический overlap, а статистический хвост.

**К 0.94–0.96:** только если в данных реально есть почти идеальная разделимость *и* мы угадываем ту же калибровку gate/полярности, что у организаторов. Иначе 0.94 на одном Run — завышенное ожидание.

---

### 3. Доктор наук (квантовая физика) + инженер-криптограф

Один скаляр PSD при высоком SNR даёт грубо **~1 бит** (две моды) + редкий class2.  
Accuracy ~0.86 совместим с тем, что **~14%** объектов лежат в зоне, где этот бит не определён однозначно относительно скрытой разметки.

**К 0.94–0.96** нужен **дополнительный независимый канал** (вторая наблюдаемая / временна́я структура / метаданные). Иначе потолок близок к текущему.

Крипто-аналогия: нельзя «добрутфорсить» секрет, атакуя не тот оракул — мы бьём в PSD-оракул, а ключ может быть в другом.

---

### 4. ML-инженер (НИР, космические излучения)

В космических/детекторных данных типичен потолок unsupervised на одной фиче. Топ‑3 модели — по сути **один классификатор**.

**Где баллы:**  
(a) ошибки у долины;  
(b) class2 ≠ истинный «аномальный» класс ТЗ;  
(c) возможен другой feature contract у организаторов (другие окна/формула).

**Путь к 0.94–0.96 на практике:** полу-супервайз / псевдолейблы при внешнем сигнале, или угадать **их** контракт признаков. Без этого ожидаемый потолок **0.86–0.89**, не 0.95.

---

### 5. Венчурный инвестор (deep tech, 20 единорогов)

ROI: **0.46 → 0.86** — уже step-change. Дожимать 0.86→0.88 — допустимо; обещать **0.94–0.96** на той же оси — red flag (переоценка).

Инвестировал бы в: (1) разведку метрики/формата разметки; (2) 1–2 радикально других признака; не в сотый submission по квантилям.

**Вердикт:** 0.94–0.96 как цель спринта — **нет**; moonshot при новом источнике сигнала — maybe.

---

### 6. Илон Маск

«Вы оптимизируете калибр вентиля, а нужно понять, что вообще считает Kaggle.»

- Если private labels ≈ детерминированный PSD-split с **их** окнами — высокий score **возможен**, найдя их gate (тогда 0.94 не фантазия).  
- Если labels = физика + шум + ручная эвристика — **0.95 не взлетит**.

Следующий ход: не +0.001 к `q`, а **взломать постановку** (метрика, remap, правило class2). First principles > grid search.

## Сводка консилиума

| Вопрос | Ответ |
|---|---|
| Где теряются баллы до 0.94–0.96? | Не в «недонастроенном q», а в **~8–10% событий**, которые одномерный PSD + квантильный class2 **принципиально** плохо согласует со скрытой разметкой (или разметка использует другой контракт). |
| Может ли кто-то предложить путь к **0.94–0.96**? | **Гипотезы — да. Рабочий план с высокой вероятностью — нет** на текущей оси. |
| Единственный реалистичный moonshot | Угадать **feature contract организаторов** (другие gate/формула/правило class2) *или* найти вторую независимую наблюдаемую. |
| Честный потолок сейчас | **~0.86–0.88** при везении; **0.94–0.96** — только при скрытой почти-детерминированной структуре, в которую мы ещё не попали. |

### Согласованные гипотезы «куда утекают баллы»

1. **Чужие окна/формула** у ground truth → наш лучший PSD систематически смещён на тысячах событий.  
2. **Class2 в ТЗ ≠ квантили PSD** (overlap / morph / uncertainty) → неправильно «жертвуем» ~3% и недобираем другие.  
3. **Метрика с оптимальным remap / особым учётом классов** — локальные LB-числа могут быть обманчивы.  
4. **Неразрешимый overlap** двух типов → физический потолок ≪ 0.95.

### Одной фразой

Консилиум единодушен: **0.858 — сильный локальный оптимум семейства**; **0.94–0.96 не достаётся тюнингом**. Единственный шанс — сменить постановку признака/метки, не ещё один `n_sigma`.
