## Вердикт

Эпик — **спека offline ML**, не сетевой сервис. Классических RCE/SQLi/auth-дыр в тексте нет.

Риск для проекта: **низкий–умеренный**. Основная угроза — не «взлом сервера», а **целостность пайплайна**: `NaN`/`inf` после делений, произвольный path load, supply chain через `pip`, pickle-артефакты.

Находки **внесены в эпик** как DoD **D10–D12** и усиления US-1/3/4/5/6/8 (редакция после этого ревью).

## Находки (до вливания в эпик)

### 1. Высокий для целостности — деление на ноль / NaN (закрыто D11 + EPS)

Формулы эпика: `x_norm = x0 / peak_above`, `psd = (long−short)/long`, `valley_ratio` по плотностям. Без `EPS`/`isfinite` → отказ анализа / порча submission.

**Митигация в эпике:** `EPS` на знаменателях; D11; `qc_nonfinite`; `ValueError` вместо голого `assert`.

### 2. Средний — arbitrary file read (закрыто D10)

«Без upload» ≠ allowlist путей. Ноутбук ходит по `/content`, `/datasets`, cwd.

**Митигация:** D10 — фиксированный `DATA_NAME` + allowlist корней; путь вне списка → ошибка.

### 3. Средний — supply chain / pickle (закрыто D12)

Тихий `pip` и `joblib` уже в зоне риска репозитория. Prep не должен добавлять deps и сериализовать через pickle.

**Митигация:** D12 — без `pip install` в § Preprocessing; артефакты только CSV/NPY/JSON; опционально SHA256 входного файла.

### 4. Низкий–средний — compute DoS сеткой PSD (закрыто в US-3)

Сетка × 23k волн без bound.

**Митигация:** лимит размера сетки; калибровка на subsample + финальный full pass.

### 5. Низкий — `assert` как gate (закрыто в D1 / US-1)

`assert` срезается `-O`.

**Митигация:** `ValueError` в `src/`.

### 6. Процесс / integrity (не CVE)

| Риск | Статус |
|---|---|
| Legacy §5–§9 как «итог» | баннер D9 |
| Подмена data-файла | опциональный SHA256 (D12) |
| Ручная «нарисовка» class 2 позже | вне скоупа; флаги без финальных меток |
