# Рекомендации по улучшению score на Kaggle

**Контекст:** первая отправка `submission.csv` — accuracy **0.36568** (место 33).  
Внутренний silhouette модели v1 ≈ **0.71**, цель ТЗ — accuracy ≥ **0.84**, целевой порог > **0.85**.

## Почему silhouette ≠ accuracy

| Метрика | Что измеряет |
|---------|----------------|
| **Silhouette** | Компактность и отделимость кластеров в выбранном пространстве признаков |
| **Kaggle accuracy** | Совпадение с скрытой разметкой (с оптимальной перестановкой меток 0/1/2) |

Высокий silhouette не гарантирует высокую accuracy, если структура кластеров не совпадает с истинными классами.

## Диагноз модели v1 (`two_stage_gmm_robust`)

| Кластер | Доля (примерно) |
|---------|-----------------|
| 0 | **~88–94%** |
| 1 | **~5–6%** |
| 2 | **~6%** |

Почти все события попали в один класс. При более сбалансированной истинной разметке (γ / нейтроны / аномалии) accuracy падает, даже если кластеры «хорошо отделены» внутренней метрикой.

Дополнительные факторы v1:

- **Isolation Forest** и порог posterior переносят точки в кластер 2, но не выравнивают классы 0 и 1.
- **Перекодировка по заряду** частично компенсируется на Kaggle перестановкой меток, но не спасает при ~90% в одном кластере.
- **KMeans на (пик, заряд)** даёт другое разбиение (ARI с v1 ≈ **0.08**) — возможно, ближе к физике задачи.

## Рекомендации по приоритету

### 1. Сменить критерий отбора модели

Не максимизировать только silhouette. Штрафовать экстремальный дисбаланс (max-кластер > 70%) и задавать целевую долю кластера 2 (~5–15%).

Кандидаты для A/B на Kaggle:

- **PC1 + хвосты PSD** → ~43% / 47% / 10%
- **GMM-3 на QuantileTransformer(PSD, …)** → ~48% / 22% / 30%
- **KMeans k=3 на (пик, заряд)**

### 2. Ослабить двухэтапную схему v1

- Отключить **Isolation Forest**
- Подобрать `confidence_threshold` (высокий порог даёт почти пустой кластер 2 при 94% в классе 0)
- Сравнить **GMM k=3** только на `[пик, заряд, PSD]` с remap «меньший кластер → 2»

### 3. Методология Description

- Порог по **PSD** и **1-й ГК** (амплитуда × заряд)
- **Голосование** PSD + GMM-2 + PCA, затем явные аномалии в класс 2
- Подбор **short gate** и **offset** для PSD

### 4. Признаки

- Кластеризация по отклонению от базовой линии / нормированной форме импульса
- 2D **(заряд, пик)** + PSD без тяжёлого PCA в финале

### 5. Калибровка под Kaggle

Без разметки нельзя гарантировать **>0.85**. План:

- Несколько submission с разным балансом кластеров
- Уточнение по score на лидерборде
- Учитывать, что лидеры сейчас ~**0.44**

## Ожидаемый эффект

| Действие | Ожидание |
|----------|----------|
| Сбалансированные кластеры 0/1/2 | **0.37 → 0.42–0.48** (проверка только на Kaggle) |
| Тонкая настройка PSD + GMM | +0.02–0.05 |
| **>0.85** без разметки | маловероятно при текущем unsupervised-подходе |
