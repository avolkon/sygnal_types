План **правильный по вектору**. Корневая причина — мёртвый PSD / charge без пьедестала и, с высокой уверенностью по числам ноутбука, **неверная ось полярности**. Эпик в текущей редакции готов к реализации: S0-блокер, три контракта окон, default PSD, численный gate, disclaimer legacy.

## Соответствие as-is ноутбука (якорь)

Код `extract_features` (§4) подтверждает диагноз:

```python
baseline = x[:, :50].mean(axis=1)     # считается, но НЕ вычитается из x
charge   = x.sum(axis=1)              # sum(500), без ROI
short    = x[i, p+3 : p+3+30].sum()   # окно от argmax
psd      = short / (charge + 1e-9)    # short/long, не (long-short)/long
snr      = peak / (baseline + 1e-9)   # ≈ 1.0005
```

## Архитектурные требования (зафиксированы в эпике)

### 1. Полярность — входной блокер S0

По числам ноутбука (без отдельного прогона): диапазон **0…14838**, `peak ≈ baseline` у всех ~23k волн. Рабочая гипотеза с **высокой уверенностью**: отрицательный импульс ФЭУ; `argmax` ловит пьедестал, сигнал — провал вниз.

Без `x_pos` вычитание `x - baseline` даёт `max≈0` → ROI/PSD снова мёртвые на новой оси.

**В эпике:** US-0 = XS, первая ячейка prep: `row_min`/`argmin` + визуал 20–50 волн + константа `POLARITY` + дальше только `x_pos`. Визуал обязателен (одних агрегатов недостаточно).

### 2. `snr≈1.0005` — индикатор, не только «починить формулу»

Старый SNR оставлять в отчёте prep как «до»; новый — `peak_above_baseline / noise_std` на верной оси. Сравнение в US-1.

### 3. `signal_extraction.py` — не эталон 3σ

Модуль режет по 40%-decay, не вычитает пьедестал, тот же SNR. В S1 — **переписать**; ноутбук вызывает `src`.

### 4. Три контракта окон

| Контракт | Роль |
|---|---|
| ROI 3σ | charge / long |
| decay 40% | время высвечивания |
| PSD offset/short | форма |

Не склеивать (иначе повторится каша §4 / текущего `src`).

### 5. Default PSD = `(long − short) / long`

`short/long` — только A/B. Иначе бесконечный grid без якоря.

### 6. Численный gate `valley_ratio`

```text
valley_ratio = density(valley) / mean(density(mode1), density(mode2))
gate OK ⇔ valley_ratio < VALLEY_RATIO_MAX   # default 0.7
```

На PSD **или** decay. Мод < 2 → FAIL; мод > 2 → две доминирующие / документировать. Порог — константа, калибруемая.

### 7. Decay на верной оси, смысл Description сохранён

Порог на `x0`:

```text
thr = (1 - DECAY_FRAC) * peak_above_baseline   # DECAY_FRAC=0.40 → уровень 60% амплитуды
```

Не на сыром `x`. Нормировка default: `x_norm = x0 / peak_above_baseline`.

### 8. US-8 = M + legacy-баннер (D9)

После prep §5–§9 физически устаревают. Баннер сразу после § Preprocessing: модели ниже — legacy до EPIC-FE; квота 5% условна.
