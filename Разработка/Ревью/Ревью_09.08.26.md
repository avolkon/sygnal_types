## 3. Анализ текста задания: откуда «5%» для класса 2

### Что есть в ТЗ / Overview

В `ТЗ2.txt` про класс 2 сказано только качественно:

- кластеров **три**;
- **0 и 1** — два типа частиц (γ / нейтроны);
- **2** — аномальные, смешанные или выбросы / не поддающиеся однозначной классификации.

**Доли ~5% (или любой другой процентной квоты) в ТЗ нет.**  
Нет требования «сначала k=2, потом дорисовать аномалии фиксированным процентом».

Научный Overview (паратерфенил, упругое рассеяние на водороде, γ-фон) объясняет **зачем** разделять γ и нейтроны, но **не задаёт** размер третьего кластера.

В `Description.txt` методология про **бинарное** разделение (PSD, время высвечивания, 1-я ГК). Встречающееся там «5%» — это **отступ по амплитуде** при анализе времени высвечивания, а не доля класса 2.

### Откуда 5% взялись в решении

Цепочка из внутренней эволюции репозитория, не из текста задания:

1. Схема «2 физических типа + хвост» — мост между Description (k≈2) и ТЗ (нужен класс 2).
2. Квота ~5% зафиксирована в проектных документах:
   - `План_реализации_сессионный.md` — `GMM(2) + top 5% uncertainty → класс 2`;
   - `Рекомендации_улучшения_Kaggle.md` — целевая доля класса 2 ~5–15% как эвристика;
   - `Итоговый_отчёт.md` — прямо: порог 5% подобран **эмпирически по Kaggle**, не по калибровочному источнику.
3. В ноутбуке это стало критерием выбора модели («единственная с ~5% в классе 2») + перебор 3% / 5% / 7%.

### Уточнение критики «класс 2 нарисован»

| Слой | Оценка |
|---|---|
| Схема «GMM-2 → неуверенные → класс 2» | Согласуется с ТЗ и с Description |
| Фиксация ровно **5%** и отбор модели по «нужной доле» | Спорно: доля не из ТЗ и не измерена из данных; задана заранее |

Спорно не выделение uncertain-хвоста, а **жёсткая квота** и формулировки вида «~5% по ТЗ».
