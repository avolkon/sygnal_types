# Роли и навыки: сессионный проект «Классификация типов сигналов»

**Задача:** кластеризация 23 479 импульсов сцинтилляционного детектора (паратерфенил) на 3 класса: γ, нейтроны, аномалии.  
**Сдача:** один воспроизводимый `.ipynb` + публичный GitHub + `submission.csv`.  
**Теория:** методы лекций PCA / SVD / LDA / ICA — см. `Пример_ДЗ1/Разработка/Матчасть_PCA_LDA_ICA.md`.  
**Ориентир оформления:** `Пример_ДЗ1` (работа в репозитории → единый ipynb для платформы).

## 2. Физик-ядерщик (эксперт по детектору и импульсам)

**Зона ответственности:** **физическая интерпретация** на всех этапах — не только «дата-инженер с графиками».

**Компетенции:**
- сцинтилляция, паратерфенил, регистрация γ и нейтронов;
- **PSD** (pulse shape discrimination): почему нейтронный импульс длиннее из‑за упругого рассеяния на водороде;
- порог 3σ, базовая линия, время спада 40% — связь с шумом ФЭУ и длиной импульса;
- участие в **EDA**: выбор примеров waveform («типичный γ», «типичный нейтрон», «подозрительный»);
- экспертное заключение после кластеризации: соответствуют ли кластеры 0/1/2 физическим популяциям;
- критика признаков: когда PCA/ICA «смешивают» физический смысл и это нужно проговорить.

**Формат в ноутбуке:** отдельные markdown-блоки **«Заключение физика»** после EDA, после извлечения признаков и после выбора модели — простым языком, с отсылкой к данным на графиках.

**Не использовать:** шаблон «нобелевский лауреат»; тон — студент-физик МИФИ с пониманием предметной области.

## 3. ML-инженер (без учителя, ядерная физика)

**Профиль:** специализация — **обучение без учителя**; образование и опыт научной работы в области **ядерной физики / детектирования излучения** (понимает и данные, и алгоритмы).

**Зона ответственности:**
- применение методов **лекций** к задаче кластеризации сигналов;
- сравнение **5 моделей** с разной математической логикой;
- внутренние метрики (silhouette, Davies–Bouldin, Calinski–Harabasz), размеры кластеров;
- обоснование выбора финальной модели с учётом **и** метрик, **и** физики;
- `random_state=42`, воспроизводимость.

**Инструменты из матчасти (обязательно применить в ноутбуке):**

| Метод лекции | Где в проекте |
|--------------|---------------|
| **PCA / SVD** | снижение размерности признаков или волновых форм; scree plot, доля дисперсии |
| **ICA (FastICA)** | разделение «смешанных» компонент импульса; сравнение с PCA |
| **LDA** | *концептуально*: почему без меток не применяем напрямую; опционально — визуализация псевдо-меток после кластера |
| **GMM** (смесь Гауссов) | модели на смеси распределений (как в Description) |
| **KMeans** | baseline в пространстве признаков / PC |
| **Иерархическая кластеризация** | dendrogram на подвыборке для выбора k |

**Пять моделей для сравнения (черновик):**

| # | Модель | Связь с лекцией / физикой |
|---|--------|---------------------------|
| 1 | KMeans k=3 на (peak, charge, PSD) | baseline кластеризация |
| 2 | GMM-3 + QuantileTransformer | смесь распределений (Description §2.3.2) |
| 3 | **PCA** (n по 90–95% дисперсии) + KMeans k=3 | матчасть PCA/SVD |
| 4 | **FastICA** на признаках / усечённой волне + KMeans k=3 | матчасть ICA |
| 5 | GMM-2 + доля неуверенных → кластер 2 | композиция «2 типа + хвост» (финал) |

**Чего избегать:** скрытый код в `src/` без объяснения; сетки на сотни конфигов; выводы без переменных из ячеек выше.
