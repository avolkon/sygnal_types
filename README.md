# sygnal_types

Современные задачи ядерной энергетики, радиационного контроля, фундаментальной и прикладной физики требуют высокоточной регистрации и анализа излучения различной природы. Важной составляющей этих задач является возможность отделения компонентов ионизирующего излучения, таких как гамма-кванты и нейтроны, в условиях сложного фонового окружения.

## Структура репозитория

В **корне проекта**:

| Путь | Содержание |
|------|------------|
| `Run200_Wave_0_1.txt` | Исходный датасет (сигналы) |
| `notebook_5_v3_experience.ipynb` | Эксперименты v3 (A/B/C), сравнение с Kaggle |
| `notebook_6_v3_model.ipynb` | **Финальный инференс** (метод C, accuracy **0.44571**) |
| `submission3c.csv` | Лучший ответ для Kaggle |
| `README.md` | Описание проекта |

Каталог **`Разработка/`**:

| Путь | Назначение |
|------|------------|
| `Разработка/Подготовка/` | Исходные материалы, черновики, пример ноутбука и сопроводительные документы |
| `Разработка/ИБ/` | Материалы по информационной безопасности (при необходимости) |
| `Разработка/Ревью/` | Итоговый отчёт и материалы ревью |
| `Разработка/Эксперименты/` | Архив ноутбуков v1–v2 и скриншотов Kaggle |

Рабочий цикл: `notebook_5_v3_experience.ipynb` → `notebook_6_v3_model.ipynb` → `submission3c.csv`.  
Итоговый отчёт: `Разработка/Ревью/Итоговый_отчёт.md`.
